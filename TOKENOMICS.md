### 3.1 Ecosystem Vault (55% - 2,750,000,000 iRC)

#### Emission Schedule (Controlled Release)


*Note: These ratios should be adjusted based on actual player metrics.*

#### Faucet vs Sink Economics

**FAUCETS (Tokens leaving vault → Players)**
- Daily login rewards
- Quest/mission completion
- PvP victory rewards
- Tournament prizes
- Referral bonuses

**SINKS (Tokens returning vault ← Players)**
- Vehicle purchases (FiveM)
- Property purchases (FiveM)
- Character upgrades (Turn-based)
- Cosmetic items (All games)
- Fast-pass/skip timers
- Guild creation fees

**⚠️ CRITICAL RULE: Sinks must equal or exceed Faucets**

```
Monthly Faucet Output: 34,375,000 iRC
Required Sink Return:  ≥34,375,000 iRC

If Faucet > Sink → Inflation → Token price drops
If Sink > Faucet → Deflation → Rewards feel scarce
```
